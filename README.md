## 一、产品简介

### 1.1 这是什么

微影不是传统意义上追求影院级体验的视频播放器。它解决的是一个非常具体的场景问题：

- 你想在写代码、改文档、回消息时「顺手挂着」视频
- 你希望播放器尽量不挡事、不抢焦点、不容易被第一眼注意到
- 当有人靠近或共享屏幕前，播放器能比手动反应更快地隐藏并静音

一句话总结：**这是一款以「快速收起、低存在感、恢复顺手」为核心竞争力的摸鱼工具。**

### 1.2 技术架构

微影采用「控制台 + 独立播放窗口」的双窗口架构：

| 层 | 技术 | 说明 |
|---|---|---|
| 桌面容器 | Electron 37+ | 负责窗口、托盘、快捷键、自动收起逻辑 |
| 播放后端 | mpv.exe（JSON IPC 通信） | 负责实际视频解码与播放，性能优异 |
| 界面 | 原生 HTML/CSS/JS | 轻量控制台，无框架依赖 |
| 人脸检测 | Chromium FaceDetector API | **完全本地运行，不上传任何图像** |

## 二、快速上手

### 2.1 首次启动

双击运行程序后会发生：

1. **系统托盘图标出现** — 右下角任务栏显示微影图标，右键可展开快速菜单
2. **控制台窗口打开** — 这是你的控制中心（不是播放窗口！）
3. **7 天试用自动开始** — 无需注册，立即享受标准版全部功能
4. **mpv 播放内核自动检测** — 程序会自动寻找可用的 mpv.exe

### 2.2 播放你的第一个视频

有 4 种方式打开视频：

| 方式 | 操作 |
|---|---|
| **按钮** | 控制台顶部点击「打开视频」 |
| **快捷键** | 按 `Ctrl + Alt + O` |
| **托盘菜单** | 右键托盘图标 → 打开视频 |
| **最近播放** | 控制台「最近播放」栏点击历史记录 |

打开后 mpv 独立播放窗口会弹出并开始播放。

### 2.3 核心快捷键（全局有效）

无论你在哪个窗口，以下快捷键随时生效：

| 快捷键 | 功能 | 说明 |
|---|---|---|
| `Ctrl + Alt + H` | **隐藏 / 恢复**播放窗口 | 最常用的「保命键」 |
| `Ctrl + Alt + O` | 打开视频文件 | 弹出文件选择框 |
| `Ctrl + Alt + P` | 播放 / 暂停 | 切换播放状态 |
| `Ctrl + Alt + M` | 静音 / 取消静音 | 一键静音 |
| `Ctrl + Alt + S` | 打开设置面板 | 偏好配置 |

> **重要**：按下以上快捷键组合时，程序会执行对应动作，**不会触发自动隐藏**。其他普通按键仍会触发输入隐藏。

## 三、核心功能详解

### 3.1 🔥 自动隐藏（核心差异化功能）

这是微影最重要的功能。有两种自动触发模式：

#### 模式一：鼠标/键盘输入触发（默认开启，标准版可用）

**触发条件**（同时满足）：
- 视频正在播放中（非暂停状态）
- 设置中「鼠标/键盘输入时自动隐藏」已开启
- 授权状态有效（试用中 / 已激活标准版或以上）
- 不在冷却时间内

**触发动作**：
1. mpv 播放窗口**立即消失**
2. 音频**立即静音**
3. 根据设置决定是否同时暂停播放

**检测机制**：
- **鼠标移动**：每 16ms 轮询一次光标位置，检测到移动即触发
- **键盘按键**：通过 PowerShell 子进程调用 Win32 `GetAsyncKeyState` 监听全局键盘（排除修饰键 Ctrl/Alt/Shift/Win），任意非修饰键按下即触发

**冷却时间**（防抖动）：
- 默认 1.2 秒，可在设置中调整为 0.8 / 1.2 / 2.0 / 3.0 秒
- 隐藏后短时间内不会重复触发，避免刚恢复又被连续收起

#### 模式二：摄像头人脸检测触发（需手动开启，高级版可用，正在开发中...）

**隐私承诺**：
- ❌ 不上传任何图像或特征到服务器
- ❌ 不保存摄像头画面
- ❌ 不后台静默启用
- ✅ 所有检测完全在本地 Chromium 内核运行
- ✅ 仅做「本人 / 非本人」二分类判断

**使用步骤**：
1. 设置 → 开启「检测人脸时自动隐藏」
2. 首次使用点击「录入本人」→ 正对摄像头保持 1-2 秒
3. 程序生成本人脸部灰度特征向量（16×16 归一化）
4. 检测摄像头画面中出现人脸后，与本人模板比对
5. 连续 2 帧检测到「非本人」或「多张人脸」→ 立即隐藏

**检测参数**：
- 相似度阈值：0.17（欧氏距离）
- 触发连续帧数：2 帧
- 检测间隔：每帧轮询

### 3.2 快速恢复

隐藏后通过以下方式恢复，**所有状态完整还原**：

| 恢复方式 | 操作 |
|---|---|
| 快捷键 | `Ctrl + Alt + H` |
| 控制台按钮 | 点击「恢复」按钮 |
| 托盘菜单 | 右键托盘 → 恢复上次播放 / 显示播放器 |

**恢复内容包括**：
- ✅ 播放窗口显示位置
- ✅ 视频播放进度（精确到秒）
- ✅ 音量与静音状态
- ✅ 倍速设置
- ✅ 当前视频文件
- ✅ 暂停 / 播放状态（根据设置）

### 3.3 断点续播

程序会自动记住你的播放状态（存储于 `%APPDATA%/moyu-player/settings.json`）：

- **上次文件路径** — 启动后可一键「恢复上次播放」
- **上次进度位置** — 恢复时从你上次看到的位置继续
- **上次音量** — 70%（默认）
- **上次静音状态** — 还原是否静音
- **最近播放列表** — 最多保存 8 个历史文件，一键清空

### 3.4 倍速播放

控制台提供 6 档倍速：
- 0.5x（慢速）
- 0.75x
- 1x（正常）
- 1.25x
- 1.5x
- 2x（快速）

### 3.5 网络视频播放

微影还支持直接播放多个平台的公开网络视频（粘贴分享链接即可）：

**支持平台**：
- 抖音（v.douyin.com）
- 小红书（xiaohongshu.com）
- Bilibili（bilibili.com / b23.tv）
- TikTok（tiktok.com）
- YouTube（youtube.com / youtu.be）
- Instagram（instagram.com）
-其他平台可单独定制

**使用方式**：
1. 控制台顶部点击「网络视频」按钮
2. 粘贴分享文案或链接（支持直接粘贴抖音口令：「… https://v.douyin.com/xxx/ 复制此链接」）
3. 点击「播放」即可播放

**特殊说明**：
- TikTok 专用 TikWM 公共 API 获取无水印直链（绕过 Cloudflare 403）
- YouTube / Instagram / TikTok 播放时自动将 SOCKS5 代理转为 HTTP 代理（解决 mpv 拉流卡死问题）
- 支持配置各平台 Cookies（浏览器导出 / 文件导入）以播放需登录内容
- 最近播放记录回填「网页链接」而非过期直链，避免污染历史

## 六、窗口管理

### 6.1 双窗口设计

| 窗口 | 负责 | 说明 |
|---|---|---|
| **控制台窗口** | 设置、控制、状态 | 有边框标准 Electron 窗口，关闭 = 退出应用 |
| **mpv 播放窗口** | 视频画面渲染 | 无边框无标题栏，由 mpv 独立进程管理 |

**优点**：
- 播放崩溃不影响控制台（恢复入口始终存在）
- 自动隐藏只隐藏播放窗口，控制台继续待命
- 控制台可最小化到任务栏，不影响观看

### 6.2 尺寸预设

控制台提供 4 档尺寸：

| 档位 | 尺寸 |
|---|---|
| 小窗 | 760 × 560 |
| 中窗（默认） | 920 × 640 |
| 大窗 | 1080 × 720 |
| 超大窗 | 1260 × 820 |


### 6.3 多屏安全回退

如果上次保存的窗口位置在当前已不可见（比如拔了外接显示器），程序会自动：
1. 检测所有显示器工作区
2. 若上次位置无任何可见区域 → 丢弃旧坐标
3. 使用默认尺寸重新定位到主屏可见区域

## 七、故障排查

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| **mpv 未检测到** | mpv.exe 不在标准路径 | 控制台 → 设置 → 点击「选择mpv.exe」手动定位，或把 mpv.exe 放到 `vendor/mpv/` 目录 |
| **自动隐藏不生效** | 试用期已过 / 未激活标准版；视频已暂停；开关未开；处于冷却期 | 检查授权状态 → 确认视频正在播放 → 检查设置开关 → 等冷却结束 |
| **人脸检测不可用** | 摄像头未连接 / 被占用；Chromium FaceDetector API 在当前环境不支持；未录入本人模板 | 检查设备管理器 → 先录入本人 → 诊断面板查看详细状态 |
| **恢复后视频从头播放** | 「恢复时继续播放」开关关闭 | 设置 → 开启「恢复时继续播放」 |
| **控制台窗口找不到** | 最小化到任务栏；被移到拔走的显示器 | 看任务栏图标；右键托盘 → 恢复控制台；重启应用（会自动回退到主屏） |
| **快捷键没反应** | 与其他软件快捷键冲突；全局注册失败 | 关闭冲突软件；控制台按钮仍可使用 |
| **启动日志在哪** | 需要排查启动问题 | 控制台 → 诊断 → 「日志」按钮；或路径 `%APPDATA%\moyu-player\startup-debug.log` |
| **诊断信息导出** | 需要发给开发者排查 | 诊断 → 「复制」或「导出」JSON 文件 |

## 八、使用技巧与最佳实践

1. **把 mpv 窗口拖到副屏角落**，主屏专注工作，余光看视频
2. **冷却时间建议 1-2 秒**：太短会频繁误触（比如刚恢复就打字），太长不够安全
3. **导出设置备份**：配好所有偏好后立即导出 JSON，换设备秒迁移
4. **Ctrl+Alt+H 是最快的保命键**，形成肌肉记忆比自动隐藏更可靠
5. **人脸检测适合开放工位**：同事经常从身后路过的场景建议录入本人后开启
6. **控制台贴右中 / 右下边**：不挡 IDE 核心编辑区
7. **最近播放别清空**：省去每次从文件管理器找文件的麻烦
8. **怀疑 mpv 挂了？** 托盘 → 选择 mpv → 重新指定路径即可自动重启播放内核

## 九、隐私与安全承诺

微影在设计上极度重视用户隐私，尤其是人脸识别部分：

| 行为 | 是否执行 |
|---|---|
| 上传摄像头画面到任何服务器 | ❌ 绝对不会 |
| 保存摄像头录像或截图 | ❌ 绝对不会 |
| 上传人脸特征向量 | ❌ 绝对不会 |
| 后台静默启用摄像头 | ❌ 必须用户手动点击开关 |
| 本地存储完整原始图像 | ❌ 仅存 16×16 归一化灰度向量 |
| 发送任何使用统计数据 | ❌ 无遥测、无埋点 |
| 读取浏览器历史 / 文件系统 | ❌ 仅访问用户主动选择的视频文件 |

试用冗余存储仅用于防止滥用试用机制，不含任何用户身份数据，仅为时间戳 + 签名。
